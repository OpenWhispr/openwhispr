IPC contract defined here.

tests with a fake CLI, and the pty dependency decision.

IPC contract (defined here, consumed by 08-03). Invoke channels: `llm-cli-detect` (no args, returns all seats),
`llm-cli-test` (seat), `llm-cli-install-start` (seat, consentedUrl), `llm-cli-install-cancel` (seat),
`llm-cli-signin-start` (seat), `llm-cli-signin-submit-code` (seat, code), `llm-cli-signin-cancel` (seat),
`llm-cli-signout` (seat), `llm-cli-get-prefs`, `llm-cli-set-pref` (key, value), `llm-cli-stream-start` (payload),
`llm-cli-stream-cancel` (streamId). Events main to renderer: `llm-cli-event` (state, install-progress, signin-prompt)
and `llm-cli-stream-part` (streamId plus part, done or error). Seat arguments are validated against the enumerated
seat ids; payloads are size-capped; every error string crossing IPC passes `redactSecrets`.

Planner-verified facts (see 08-01 context block for the full list): `claude setup-token` has no options and needs a
terminal (AAF hosts it in a pty); codex and grok device-auth need no pty (plain spawn, regex the stdout); grok has no
status command; agy has no login command. The vendored codex native exe path under the npm shim was NOT confirmed by the
planner (a directory listing was blocked by a local guard), so Task 2 discovers it with a bounded search instead of
hard-coding it.
