<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| portal -> desktop | /api/exchange response (email, licenseKey, appSlug, accountId) crosses the network |
| disk -> main | encrypted titanium-session.bin read at launch |
| renderer -> main | connector IPC calls; renderer is untrusted for policy decisions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Spoofing | titaniumSession.handleCallback | high | mitigate | Send app_slug; reject when response appSlug is missing or differs (D-02); state + PKCE checks unchanged |
| T-07-02 | Information disclosure | connector credential slots | high | mitigate | Slot keyed on sha256(Titanium accountId); account switch calls accountChanged so another account's login is never read (D-03) |
| T-07-03 | Elevation of privilege | connector policy (fork) | high | mitigate | Policy decided in main from the offline-verified license; unknown states fail closed to policy_unavailable; renderer state never consulted (D-04, D-05) |
| T-07-04 | Tampering | titanium-session.bin | medium | mitigate | safeStorage encryption unchanged; license re-verified offline on every load; accountId only from the exchange |
| T-07-05 | Information disclosure | TitaniumAuthState broadcast | low | mitigate | Raw accountId not exposed to renderer, only accountBound |
| T-07-06 | Repudiation | stale in-flight exchange | low | accept | Existing generation guard already discards superseded exchanges |
</threat_model>
