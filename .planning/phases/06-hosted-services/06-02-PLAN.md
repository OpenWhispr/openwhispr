<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| main -> stt-api | License key leaves the desktop as a bearer |
| browser -> loopback server | OAuth redirect into 127.0.0.1 (calendars direct, Slack/Linear via relay) |
| renderer -> main | Untrusted renderer asks main to run a web search |
| build shell -> installer | OAuth client ids written into resources/.env |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-08 | Information disclosure | titaniumServiceKeyFor | high | mitigate | Exact-host allow-list (DEFAULT_STT, SERVICES_URL, serviceHosts), https only; test rejects other hosts; key never returned to renderer |
| T-06-09 | Spoofing | relay base override | medium | mitigate | SLACK/LINEAR_OAUTH_REDIRECT_URI keep their https-only check; SERVICES_URL comes from the signed build config |
| T-06-10 | Tampering | calendar result page | low | mitigate | renderOAuthResultPage escapes text; page carries no tokens or query values |
| T-06-11 | Information disclosure | fork-write-env / harness output | medium | mitigate | Scripts print key names and booleans only; tests assert no value appears on stdout/stderr |
| T-06-12 | Elevation of privilege | Google desktop client secret in installer | low | accept | Non-confidential for installed apps (RFC 8252, Google installed-app guidance); PKCE in use; D-12 |
| T-06-13 | Denial of service | web search from renderer loop | low | mitigate | Server rate limit (06-01 D-05); RATE_LIMITED surfaced, no client retry |
</threat_model>
