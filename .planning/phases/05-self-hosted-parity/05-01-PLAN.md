## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| desktop -> stt-api WS upgrade | Untrusted client offers subprotocols and a bearer header |
| desktop -> /v1/chat/completions | Untrusted system and user prompt text reaches the Claude CLI |
| stt-api -> Claude CLI process | Server-side process with the owner's subscription OAuth |
| operator -> Coolify env | Operator token and model config |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-05-01 | Spoofing | streamRoute upgrade, chatCompletionsRoute | high | mitigate | Both use the existing `buildAuthorizer` (operator token or license with revocation check); 401 cases tested in Task 2 and the existing stream tests |
| T-05-02 | Information disclosure | chatCompletionsRoute logging | high | mitigate | Logs carry request id, char counts, duration, outcome only; no message content, no Authorization header; error bodies never include CLI stderr (Task 2 behavior) |
| T-05-03 | Elevation of privilege / DoS | /v1/chat/completions as a general Claude proxy | medium | mitigate | Exactly system+user string content, no tools/functions/stream/n>1, 32,000-char input cap, clamped max tokens, shared concurrency limit and 180 s timeout; residual business exposure accepted as B5 |
| T-05-04 | Denial of service | online stream pool (cap 2) | medium | accept | Existing idle timeout (30 s) and 503 on a busy pool; capacity measured in Task 4 (B2) |
| T-05-05 | Tampering | subprotocol negotiation | low | mitigate | Only the exact `stt-segments` value is selected; anything else selects none and gets today's frames (Task 1 case c) |
| T-05-06 | Elevation of privilege | Claude CLI spawned with untrusted prompt text | critical | mitigate | Shared argv disables all CLI tools and MCP servers; asserted on argv in `test/claudeCliComplete.test.js` (Task 2) |
| T-05-07 | Information disclosure | prod verify scripts | high | mitigate | Token read from env only, never printed or written; scripts print only pass/fail and counts |
| T-05-SC | Tampering | npm installs | low | accept | No new packages; `ws` already a dependency |
