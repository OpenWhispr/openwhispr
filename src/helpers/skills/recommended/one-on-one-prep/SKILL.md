## Purpose

Better one-on-ones with less preparation.

## When to use

When the user asks to prep for a 1:1 or one-on-one.

## Steps

1. Find the last 1:1 note with that person.
2. List what has changed since then: open items, decisions, new topics.
3. Suggest two questions to ask.

## Output format

Since last time · Open items · Ask.

## Avoid

- Judgements about the person's performance.
