# Android Parakeet integration

Decision: Parakeet v3 is the Android speech engine, following Josh's 2026-10-14 preference. It is an inference candidate whose device performance must be measured, not a claim that NVIDIA's server benchmarks apply to phones.

- Runtime: Sherpa-ONNX 1.13.8 built from checksum-pinned source with TTS, speaker diarization, C API, command-line tools and WebSockets disabled. `scripts/build-android-speech.py` runs from Gradle, uses the project NDK and SDK CMake 3.22.1, and caches its source/build under the Gradle user directory. Only Kotlin bindings come from the checksum-pinned official AAR. Its TTS-enabled JNI and unused C/C++ libraries are never packaged. ONNX Runtime 1.28.2 is separately checksum-pinned. The ARM64 JNI uses 16 KB ELF alignment; the APK contains only Sherpa JNI and ONNX Runtime for this integration.
- Model: NVIDIA Parakeet TDT 0.6B v3, CC-BY-4.0, converted/quantized by the Sherpa-ONNX maintainers; Hugging Face `csukuangfj/sherpa-onnx-nemo-parakeet-tdt-0.6b-v3-int8`, revision `2bda32ec70b097a55adaa07d9a7173915b43cc78`. Exact per-file hashes and byte lengths are in `src/android/models.ts`. Download is 670 MB decimal (approximately 639 MiB), separate from the app binary and RAM use.
- Runs locally on CPU, four threads. No NVIDIA GPU, hosted service or account is required after download. iPhone CoreML files cannot be reused on Android.
- Language support: bg, hr, cs, da, nl, en, et, fi, fr, de, el, hu, it, lv, lt, mt, pl, pt, ro, sk, sl, es, sv, ru, uk. Detection is automatic; selecting a supported language does not force the decoder to use that language.
- Speech/text inference is serialized. The idle runtime is released before allocating the other, prioritizing bounded RAM over warm-start latency.
- Cancellation invalidates queued/running results; the native decoder cannot be interrupted midway. Its session is never freed while decoding.
- Longer files use 25-second owned intervals with two seconds of context on each side. Word timing determines ownership so a boundary cannot split a tokenized word or duplicate overlapping text. Each inference window stays below 29 seconds; PCM is read in bounded buffers. Near-digital silence is trimmed from window edges, retaining context and original timestamps. Cancellation is checked between windows. Recording is capped at five minutes and imported audio at one hour.
- Translation, cleanup, writing and editing use a separate Qwen text model. Parakeet alone cannot establish their quality.

Initial 14 October check: Android debug build, TypeScript and thirty targeted tests passed. The first emulator run succeeded using synthetic prerecorded English audio (host microphone off): native Parakeet including initialization/conversion 1,891 ms; shared transcription stage 2,485 ms; Qwen 1.5B cleanup 6,944 ms with zero retries, then translation generation 532 ms. Spanish output: “Estaré allí en diez minutos.” Correct meaning for “I will be there in ten minutes.” This one short clip is not a general accuracy benchmark or physical-phone performance proof. Observed process memory during the combined workflow was about 2.7 GB PSS including swap; further memory tuning and physical-device validation remain needed.

Sources: [NVIDIA model card](https://huggingface.co/nvidia/parakeet-tdt-0.6b-v3), [Sherpa-ONNX Android/model documentation](https://k2-fsa.github.io/sherpa/onnx/pretrained_models/offline-transducer/nemo-transducer-models.html), [runtime release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/v1.13.8).

A 70-second synthetic WAV spanning the 25- and 50-second joins produced all four expected sentences correctly on the emulator. Native recognition took 76,950 ms before edge-silence trimming was added. This is a segmentation regression check, not a representative long-form speed benchmark. The final speech-only runtime and edge trimming were exercised by later short WAV and offline M4A checks. The 70-second segmentation fixture has not been rerun after edge trimming; no long-file speed improvement is claimed.

Full runtime/dependency notices are bundled in `src/android/licenses.json` and reachable offline from Account → Licenses & attribution. They are copied from the pinned Sherpa dependency sources, ONNX Runtime 1.28.2, llama.rn 0.12.3 and its bundled llama.cpp, and Android NDK 27.1.12297006. Regenerate/review these notices when any of those dependencies change. Eigen source remains available at its linked 5.0.1 tag; no local Eigen changes are made.

## Final packaged development check — 15 October 2026

The retained emulator has Android 16/API 36, four virtual CPU cores and 4 GB RAM. Host microphone input stayed off. These are synthetic-file checks, not physical-phone speed or microphone-quality benchmarks. Balanced Qwen 1.5B, Personal/Natural style and the default cleanup prompt are restored.

The final APK uses a source-built llama.rn 0.12.3 with unconditional prompt-token and decoded-text logging removed. The packaged-library audit found neither logging string in any llama variant; the final inference log contained neither token IDs nor the synthetic transcript. Development diagnostics retain model names, elapsed times and aggregate token counts only.
