   correctly — plain `install-app-deps` silently no-ops if a build dir exists.

   REQUIRED". Three artifacts were once all named 1.12.0.

   Implementing — REQUIRED". Skipping it shipped a progress window that could

  default at `settingsStore.ts:1171`.
