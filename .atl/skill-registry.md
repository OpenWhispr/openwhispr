## Compact Rules (auto-resolved — inject into sub-agent prompts)

### From user global CLAUDE.md
- **Commits**: Conventional Commits only. NEVER add `Co-Authored-By` or any AI attribution.
- **Never build after changes** (`npm run build`/`pack`/`dist`) unless explicitly asked.
- **Verify before asserting**: never agree with a claim without checking code/docs first. If wrong, explain WHY with evidence.
- **Questions block**: when you ask the user a question, STOP and wait — never assume the answer.
- **Strict TDD Mode is ACTIVE**: write a failing test first, then code to green. Test runner: `node --test`.

### From project CLAUDE.md
- **i18n is REQUIRED**: every user-facing string MUST use `react-i18next` (`useTranslation()` → `t("key")`). Add the key to ALL locale files under `src/locales/{lang}/translation.json` (en, es, fr, de, pt, it, ru, zh-CN, zh-TW). Never hardcode UI text. Do NOT translate brand names, technical terms, format names, or AI system prompts.
- **New IPC channel**: add to BOTH `src/helpers/ipcHandlers.js` AND `preload.js`.
- **New setting**: update `src/hooks/useSettings.ts` AND `src/components/SettingsPage.tsx`.
- **New UI component**: follow shadcn/ui patterns in `src/components/ui`.
- **New manager**: create in `src/helpers/`, initialize in `main.js`.
- **New sidecar binary**: add download script in `scripts/`, wire into `prebuild*`, add manager in `src/helpers/`, register via `sidecarRegistry.register(...)`, add fragment to `EXPECTED_BINARY_FRAGMENTS` in `sidecarReaper.js`.
- **TypeScript** for new React components. Renderer is ESM; Electron main is CommonJS (`require`).
- **Model definitions**: single source of truth is `src/models/modelRegistryData.json`.
- **Resource cleanup**: always clean temp files, listeners, and child processes.

- Runner: **Node.js built-in** (`node:test` + `node:assert/strict`). Command: `node --test` (autodiscovery from repo root).
